# Double Strike Chess Engine

This fork extends Leela Chess Zero with a once-per-game double move for each
player, ability-aware input encoding, split policy heads, policy-only play,
and optional routing to an ordinary-chess fallback network.

The [Double Strike Chess site repository](https://github.com/Raffa2005/Bachelor)
pins a compatible network and provides source build and self-hosting scripts.
The public site is https://doublestrikechess.com.

Upstream code is by the Leela Chess Zero contributors listed in `AUTHORS`.
